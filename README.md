# 🎧 DJ & Audio

## 🎛️ StemMaker

<img src="https://raw.githubusercontent.com/Elospeed/StemMaker/main/art/stemmaker_icon_1024.png" align="right" width="110" alt="StemMaker icon">

**Turn your own tracks into Traktor stem files.**
StemMaker converts MP3, WAV, FLAC and more into `.stem.mp4` files with four separate parts: drums, bass, melody and vocals. Load them in Traktor or Mixxx 2.6 (beta) and mix each part on its own.

- One small native Windows program, no Python, no setup
- Turbo engine since 2.0: 6 to 10 times faster on the CPU, uses your graphics card when it helps (NVIDIA, AMD, Intel)
- Batch conversion of whole folders, resumes where it stopped
- Built-in StemPlayer to listen to each stem before the gig
- Optional club level and bass fix for punchy, consistent stems

▶ [StemMaker 2.0 in 73 seconds on YouTube](https://youtu.be/B0LE8mc-MEM)

# 🏭 Industrial networks

## 📡 Network Ping Tool

**Check a whole list of devices with one click.**
An Excel VBA tool for industrial networks: ping PLCs, HMIs and other Profinet devices (e.g. Siemens CPUs) straight from Excel, instead of typing `ping` into a command prompt over and over.

- Fast ICMP ping via the Windows API, no extra programs needed
- Three scan modes, clean cancel, correct numeric IP sorting
- Pings one device at a time on purpose, so company firewalls and endpoint security stay calm
- Full source code also included as plain text

## 💡 LedPreResistor

<img src="https://raw.githubusercontent.com/Elospeed/LedPreResistor/main/site/img/icon-192.png" align="right" width="110" alt="LedPreResistor icon">

**Find the right series resistor for your LED.**
A free LED series resistor calculator for Windows: enter supply voltage, LED colour and current, and it picks the matching standard resistor and explains every step of the calculation with your own values.

- Standard values from the E12, E24 and E96 series, with colour bands
- Power dissipation and load check of the resistor
- Step-by-step explanation of the calculation, great for learning
- LED info and a live LED preview in the selected colour
